# Project Oasis 游戏设计文档（v0.1.0）

本文档描述 v0.1.0 的全部实际实现规则与数值。所有可调数值集中在
`src/game/config/gameConfig.ts`，本文档与代码保持同步。

## 1. 核心目标

玩家携带 2000 元从城市出发，在 **42 天内**完成：
城市 → 穿越地图 → 抵达宝库（三选一）→ 自行决定挖矿天数 → 沿不重复路线返回城市。
返回城市时携带的宝石按当局锁定的单价变现，最终资产 = 剩余现金 + 宝石销售额。

## 2. 时间系统

- 全局唯一计数 `daysUsed`，初始 0，上限 42。
- 消耗 1 天的行为：移动 1 格、查看天气预报、绿洲休整、村庄打工（市集）、追回盗贼、挖矿 1 天。
- 额外损失 1 天（不触发 20:00 天气预报询问）：沙尘暴迷路、草地陷入泥沼。
- `daysUsed > 42` 立即失败；`daysUsed == 42` 当天抵达城市仍算成功。

## 3. 阶段（Phase）

| 阶段 | 含义 |
| --- | --- |
| OUTBOUND | 去程：城市出发前往矿区入口 |
| MINING | 采矿：在矿区入口挖矿 |
| RETURN | 返程：从同一矿区入口返回城市 |
| FINISHED | 结束（胜利或失败） |

## 4. 路线不可重复规则

- **去程**：普通格不可重复经过；不允许中途重新进入城市；进入任一矿区入口即进入 MINING。
- **返程**：不得经过去程已走过的普通格，返程自身也不得重复普通格。
- **豁免**：城市、三个矿区入口（宝库格）是唯二允许重复的地点。
- 返程任意时刻若不存在合法回城路径 → 立即失败（返程路线中断）。
- 进入矿区入口时若已无合法返城路径 → 立即失败（防止挖进死胡同）。
- 去程若被围死（无任何合法移动）→ 立即失败。

## 5. 地图

固定手工地图（36 节点，59 条道路），非程序生成。地形：城市 ×1、沙漠 ×5、草地 ×22、
村庄 ×2、绿洲 ×3、矿区入口 ×3。地图包含大量分叉与环路。

南矿区（低风险）：补给密集（村庄/绿洲）、返程选择多，但去程可用路线偏短。
中央矿区（中风险）：沙漠与草地混合，需保持西侧通路。
北矿区（高风险）：连续草地长链、补给稀少、关键沙漠、返程路线受限。

自动测试验证：城市与每个矿区入口之间，存在两条除城市与该入口外内部普通格完全不重合的路径
（等价于：删去任意一个非端点节点后仍连通）。

## 6. 耐力

- 初始 5，上限 5，归零立即失败。
- 损失来源：高温 -1、沙尘暴（无帐篷时）-1、草地暴雨（未用帐篷时）-1。
- 恢复：绿洲休整（1 天 +1，每个绿洲每局一次，干涸绿洲不可休整）。

## 7. 装备

| 装备 | 价格 | 说明 |
| --- | --- | --- |
| 帐篷 | 400 元 | 每顶内部 `desertCharges = 3`，可持有多顶 |
| 指南针 | 100 元 | 单次消耗品，仅沙尘暴中使用 |

- 沙漠沙尘暴中使用帐篷：该帐篷沙漠耐久 -1，归零后整顶消失（取当前耐久最低的一顶，确定性规则）。
- 草地暴雨中使用帐篷：**整顶立即消失**（无论剩余多少沙漠耐久）。
- 商队二手帐篷 300 元，功能与普通帐篷相同（3 次沙漠耐久）。
- 购买不消耗时间；城市与村庄均可购买；繁荣市集当次访问享 8 折（320 / 80）。
- v0.1.0 不实现装备倒卖。

## 8. 天气

天气在**开局由 Seed 预生成**（每节点 × 每天一张表），天气预报看到的是真实未来。
天气只在**进入格子的当天**生效；宝库格永远安全；采矿/休整/打工等停留日不再重复判定天气。

| 地形 | 晴 | 高温 | 沙尘暴 | 暴雨 | 泥沼 | 阴 |
| --- | --- | --- | --- | --- | --- | --- |
| 沙漠 | 0.42 | 0.28 | 0.30 | - | - | - |
| 草地 | 0.62 | - | - | 0.19 | 0.19 | - |
| 村庄/绿洲 | 0.70 | - | - | - | - | 0.30 |
| 城市/矿区 | 1.00 | - | - | - | - | - |

效果：
- **高温**：耐力 -1（v0.1 规则，无装备可减免）。
- **沙尘暴**：见 §9。
- **暴雨**：玩家选择是否用帐篷（整顶消耗、不掉耐力）或硬扛（耐力 -1）；无帐篷则只能硬扛。
- **泥沼**：当天移动已完成，额外损失 1 天，停留原地。

## 9. 沙尘暴四象限

| 装备组合 | 耐力 | 时间 | 装备 |
| --- | --- | --- | --- |
| 帐篷 + 指南针 | 不减 | 不减 | 帐篷耐久 -1，指南针 -1 |
| 仅帐篷 | 不减 | **迷路额外 -1 天** | 帐篷耐久 -1 |
| 仅指南针 | **-1** | 不减 | 指南针 -1 |
| 无 | **-1** | **迷路额外 -1 天** | 无 |

- 迷路不随机传送：额外损失 1 天，玩家停留在已进入的沙漠格。
- 拥有帐篷/指南针时 UI 必须让玩家自己决定是否使用，绝不自动消耗。

## 10. 遭遇（与天气严格分离）

遭遇由开局预生成的每节点每天 roll 值决定（与天气表独立），进入格子当天判定：

| 地形 | 遭遇 | 概率 | 规则 |
| --- | --- | --- | --- |
| 沙漠 | 商队 | 0.22 | 二选一：300 元买二手帐篷（钱不够则禁用）/ 免费揭示路网距离 ≤3 的未知普通格。不耗时间 |
| 村庄 | 盗贼 | 0.30 | `stolen = min(300, 现金)`；放弃：损失 stolen；追回：耗 1 天全额找回（超 42 天会失败并提前警告） |
| 村庄 | 繁荣市集 | 0.25 | 二选一：当次访问八折购物 / 打工（1 天 +500 元）。与盗贼天然互斥（单次 roll 单结果） |
| 草地 | 牧民指引 | 0.25 | 免费揭示路网距离 ≤3 的未知普通格地形，不耗时间 |

同一天可以同时发生天气与遭遇（例如沙尘暴 + 商队），先结算天气再结算遭遇。

## 11. 绿洲

- 进入绿洲已消耗 1 天（移动），不免费恢复。
- 停留期间可执行「休整」：耗 1 天，恢复 1 耐力（上限 5）。每个绿洲每局最多休整一次。
- 绿洲是否干涸由 Seed 在开局预生成（干涸概率 0.20），首次抵达时揭晓；干涸则不可休整。

## 12. 天气预报

- 每个正常行动日结束（20:00）弹出询问：是否把下一天用于查看天气预报？
- 查看花费 1 天（该整天不能移动/挖矿/做其他事），显示**之后**连续 3 天的天气。
- 因天气预报而消耗的整天不再触发新的 20:00 询问（无递归）。
- 迷路 / 泥沼等惩罚日也不触发询问。
- 只显示**已知地形**格子的天气（亲自探索 ∪ 情报揭示 ∪ 城市/矿区），未知地形显示「未知」。

## 13. 宝库、路线风险评分与宝石定价（v0.1.1 修订）

### 13.1 固定收购价（正式规则）

三个矿区入口的宝石收购价**固定**，由玩家首次进入的矿区入口决定，进入即锁定：

| 矿区入口 | 收购价 |
| --- | --- |
| 南矿区 | 100 元/kg |
| 中央矿区 | 160 元/kg |
| 北矿区 | 240 元/kg |

（v0.1.1 调参说明：初始 100/180/280 经 14 Bot × 10k Seeds 仿真证明北矿支配，价格扫描后调整为 100/160/240，见 docs/BALANCE_LOG.md。）

价格**不再**受以下任何因素影响：

- 去程走过多少沙漠 / 草地
- 路线风险评分
- 实际受伤次数 / 天气 / 事件
- 路线长度

（v0.1.0 的「路线难度评分 → 动态售价」机制已移除：它会产生"故意绕危险路线刷售价"的错误激励。）

### 13.2 路线风险评分（仅供统计）

路线风险评分保留，但**不影响售价**，只用于：

- 结算页与进矿提示中的「路线风险评级」（★★~★★★★★）
- 开发调试与仿真分析
- 后续成就/统计系统的潜在基础

```
score = 去程地形风险和 + 最优合法返程地形风险和 + 时间冗余惩罚 + 返程稀缺惩罚
地形风险系数：沙漠 4.5、草地 7.0、村庄 -3.5、绿洲 -2.5（城市/矿区不计）
时间冗余惩罚：slack = 42 - (去程长 + 最短返程长)，低于 12 天时每天 +1.5
返程稀缺惩罚：合法返程路径数 1/2/3/≥4 条 → +10/+6/+3/0
```

- 星级阈值（score）：≥12 → ★★、≥40 → ★★★、≥85 → ★★★★、≥115 → ★★★★★（低于 12 为 ★）。
- 评分评估的是「路线客观风险」，不是玩家实际受到的伤害。

### 13.3 市场波动（默认关闭）

市场随机波动系数（0.95~1.05）机制保留为**未来实验功能**，v0.1.1 默认关闭
（`gameConfig.marketEnabled = false`）。关闭时成交价 = 固定收购价，结算页不显示市场因素行。

平衡测试阶段需要减少变量：随机性应主要来自天气、遭遇、绿洲状态与事件，而不是奖励价格本身。

## 14. 采矿

- 宝库安全：无恶劣天气、无随机伤害、不耗耐力。
- 每挖 1 天获得 2kg 宝石，玩家自行决定何时停止并返程。

## 15. 金钱与结算

- 初始现金 2000；现金任何情况下不会为负（盗贼偷窃上限为当前现金）。
- 结算（胜利）：`宝石销售额 = 宝石重量 × 最终成交价`；`最终资产 = 剩余现金 + 销售额`；
  `净收益 = 最终资产 - 2000`。
- 结算画面显示：总用时、去程天数、采矿天数、返程天数、天气预报次数、宝石重量、
  路线难度评分、星级、基础估值、市场系数、最终成交价、宝石销售额、装备支出、剩余现金、
  最终资产、净收益、本局 Seed。
- 失败时宝石无法出售，销售收入为 0。

## 16. 胜负条件

| 条件 | 结果 |
| --- | --- |
| `daysUsed <= 42` 时返回城市（带宝石） | 胜利 |
| 任何操作后 `daysUsed > 42` | 失败（超时） |
| 耐力归零 | 失败 |
| 返程不存在合法回城路径 / 采矿入口被封 / 去程被围死 | 失败（路线中断） |

## 17. 战争迷雾

- 完整道路网络始终可见。
- 未探索普通格显示 `?`；亲自进入后永久揭示；商队/牧民情报揭示的格子以「情报」样式区分。
- 城市与三个矿区入口开局即可见。
- 地图明确区分：已探索 / 已通过情报获知 / 未知。
