# Project Oasis v0.1.2 — Random Expedition 设计与变更记录

## 1. 为什么取消固定路线

v0.1.0/v0.1.1 使用 36 节点 / 59 条道路的固定手工地图。问题：

1. 玩家在数十局后完全记住"最优路线"，游戏退化为背板；
2. 固定矿价（南 100 / 中 160 / 北 240）+ 固定地图意味着"北矿收益最高"这类结论
   一旦被仿真或社区证实，选择空间坍缩；
3. 平衡调参只能围绕一张地图进行，无法验证系统在随机环境下的鲁棒性。

v0.1.2 因此把核心信息系统整体重构为 **m×n 随机二维格子地图 + 动态矿区价值**。

## 2. 随机地图规则

- 地图尺寸**固定 10×12（120 格）**——这是游戏基础规则，不是按局随机参数；
- 城市固定左下角 `(9, 0)`；Mine A / Mine B 固定在最右列 `col = 11`，
  行由 Seed 随机（不重合、最小行距 ≥ 4）；
- 普通格地形（草地 45% / 沙漠 30% / 村庄 15% / 绿洲 10%）完全独立随机，
  与位置、路线、矿区距离无关；无预制安全通道或沙漠走廊；
- 移动：上下左右四方向，每格 1 天；禁止越界、瞬移、中途回城。

## 3. 地图合法性约束

- 生成时对城市与每个矿区做 **Menger 单点删除校验**：删去任意一个非端点格后仍连通
  ⇔ 存在两条内部普通格完全不重合的路径（这是"去返程不重复"规则可完成的必要条件）；
- 校验失败或矿区价值评估找不到合法往返组合时，使用
  `seed#mapRetry1、seed#mapRetry2…` **确定性重试**（上限 200 次），
  同一主 Seed 永远得到同一张最终地图，不产生不可复现的随机；
- 全量 Seed 扫描（2000 seeds）验证：生成成功率 100%。

## 4. 动态矿值公式

矿价在 `createNewGame`（地图生成）时**客观计算**，玩家行为无法影响：

```
difficultyScore =
    最短路径跳数        × distanceWeight (2.0)
  + 去程地形风险和      × outboundRiskWeight (0.8)
  + 返程地形风险和      × returnRiskWeight (1.0)   ← 核心因素，权重最高
  + 返程稀缺惩罚        （备选走廊 < 3 条时每缺 1 条 +5）
  + 天气负载            × weatherWeight (0.25)

gemPrice = clamp(80, 320, round((base 30 + difficultyScore × scale 1.6) × jitter))
jitter ∈ [0.90, 1.10]（宝石质量 / 市场行情 / 矿脉差异，只占价值的一小部分）
```

要点：

1. **候选去程 × 返程成对评估**：对矿区每个邻格方向的最低风险去程，计算
   "烧掉它之后"的最优合法返程，取总代价最小的组合——与真实玩家的最优规划一致，
   不会把"自己封死自己"的坏路线记为 0 风险；
2. 「返程优先」兜底策略：先贪心返程、再在返程烧格约束下找去程
   （修复角矿区被"最低风险去程"封死归途导致的评估失败）；
3. 地形风险系数：沙漠 4.5、草地 7.0、村庄 -3.5、绿洲 -2.5（正值化为 Dijkstra 权重）；
4. 天气负载 = 去返程路径格在 42 天窗口内恶劣天气（高温/沙尘暴/暴雨/泥沼）平均天数；
5. 禁止用于定价的信息：玩家实际路线、绕路程度、耐力损失、装备消耗、遭遇天气。
   价格生成后永久锁定，进矿只是读取（同 Seed 可复现，绕路/受伤/用装备均不改变）。

开发模式显示 `difficultyScore`，正常 UI 只显示 `¥xxx/kg`。

## 5. 天气预报机制（相对 v0.1.1 的重做）

| 项 | v0.1.1 | v0.1.2 |
| --- | --- | --- |
| 触发 | 每日 20:00 询问，花 1 整天 | 主动购买/使用，不占行动日 |
| 成本 | 1 天 | 购买包：**maxDays 永久 -1**；使用：0 |
| 内容 | 未来 3 天（全已知格） | **只预报明天** |
| 范围 | 全图已知格 | 当前格 + 8 邻域（内部 9 / 边缘 6 / 角落 4 格） |
| 储存 | 无 | 购买 +3 次（自动用 1），剩余可储存、不过期、可带入返程 |
| 迷雾 | 只显示已知地形格 | 未知格也显示天气（情报价值），但不揭示地形 |

失败边界：`daysUsed == maxDays` 当天回城仍算成功；`daysUsed > maxDays` 立即失败；
购买导致超额时直接判负（UI 预先禁用）。

## 6. Encounter 生成机制

- 每个普通格的遭遇在**地图生成阶段按 Seed 预生成**（25% 基础概率，
  `gameConfig.encounter.baseProbability`）；
- 每格每局最多触发一次（首次进入时）；原地停留/等待/滞留不重新抽取；
- 地形事件池：沙漠→商队；村庄→盗贼 50% / 市集 50%；草地→牧民；
  绿洲→无（干涸是绿洲自身状态）；城市/矿区→无；
- 与天气严格分离，可同日叠加（先天气后遭遇）；
- 同一 Seed → 相同地图 + 相同地形 + 相同天气 + 相同矿区 + 相同矿价 + 相同遭遇。

## 7. 与 v0.1.1 的 Breaking Changes

| # | 旧（≤ v0.1.1） | 新（v0.1.2） |

# 9. v0.1.2a — Rules Patch（2026-09-13）

规则修正与机制补全。除明确修改项外，v0.1.2 全部数值与机制保留。

## 9.1 数值修改

| 项 | v0.1.2 | v0.1.2a |
| --- | --- | --- |
| 地形比例 草:沙:村:绿 | 45/30/15/10 | **40/30/20/10**（当前测试值，真人试玩后再微调） |
| Encounter 基础概率 | 25% | **35%** |
| 事件池内部数值 | 不变 | 不变（村庄仍 50% 盗贼 / 50% 市集） |

## 9.2 原地停留与宿营重做

| 地点 | 规则 |
| --- | --- |
| 城市 | 无限免费停留（不耗帐篷/金钱，无收益） |
| 村庄 | 无限免费停留（安全住宿点；不回血、不刷遭遇） |
| 野外（沙漠/草地/绿洲） | **宿营**：必须有帐篷，玩家选择具体一顶，耐久 -1 |
| 矿区空等 | **宿营**：必须有帐篷、耐久 -1（挖矿本身不耗帐篷） |

- 无帐篷禁止野外主动停留（不允许强行露宿）；
- 宿营日天气照常结算；宿营不赚钱/不回血/不刷遭遇/不触发绿洲恢复。

## 9.3 帐篷逐顶管理

- 每顶帐篷独立记录耐久（Tent A 3/3、Tent B 1/3……），禁止合并总数；
- **一切消耗（宿营/沙尘暴/草地暴雨/绿洲修整/矿区等待）由玩家指定具体帐篷**；
  系统不自动选择；
- 草地暴雨规则不变：所选帐篷**整顶报废**（1/3、2/3、3/3 均一样）；
- 普通消耗：3/3 → 2/3 → 1/3 → 报废；
- Bot 与测试默认策略：优先消耗剩余耐久最低的一顶（残值损失最小）。

## 9.4 绿洲机制补全

- **有水绿洲·修整**：1 天、+1 耐力，必须拥有帐篷并消耗其 1 点耐久；
  每绿洲每局一次（保留）；
- **有水绿洲·停留**：与修整分离的独立行为（1 天、帐篷 -1、不恢复耐力）；
- **干涸绿洲**：不能修整；仍可按普通野外宿营停留。

## 9.5 天气预报保密

- 天气预报**只能预测自然天气**，绝不显示或暗示盗贼/商队/市集/牧民等人为 Encounter；
- Weather 与 Encounter 继续严格分离（同 Seed 可复现但玩家不可从预报推知遭遇）。

## 9.6 提前判负（内部裁判）

- 每次行动结算后后台运行 `evaluateViability`：
  - 不存在任何合法完成路线 → `NO_LEGAL_ROUTE`；
  - 最短合法完成天数（乐观下界）> 剩余时间 → `INSUFFICIENT_TIME`；
- 裁判使用保守下界（出界阶段忽略新去程烧格），绝不误判；
- `minimumLegalCompletionDays` 为内部信息：UI 不显示最短天数/最短路线/最优路径，
  失败信息只说明原因类别；
- 天气预报包购买执行同一检查：购买导致必败 → 禁止购买
  （提示"剩余时间不足"，不泄露内部天数）。

## 9.7 宝石价值（v0.1.2a 重定义）

- **废除** v0.1.2 的复杂主公式（距离×2 / 去程×0.8 / 返程×1.0 / 走廊稀缺 / 天气负载）；
- **新基准**：该矿区「最短合法往返方案」（城市→矿→城市，去返程普通格不重复，
  不穿另一矿区）的客观危险程度：
  - 主准则：往返总长度最短（节点拆分最小费用流精确求解）；
  - 同长度：取客观风险最低者（确定性次准则）；
- `gemPrice = clamp(80, 320, round((10 + roundTripRisk × 2.0) × jitter))`，
  jitter 0.90~1.10 保留为小幅修正；
- 玩家实际绕路/受伤/用装备**不可能**抬高价格（基准与玩家行为完全解耦）；
- **价格保密**：全程不显示精确单价（开局/途中/到达/挖矿均无），
  成功返城后结算页显示「最终鉴定单价」；
- 地图/侧栏/日志中的价格展示全部移除；Mine 情报只显示坐标与"价格返城后鉴定"。

## 9.8 游戏前完整规则
