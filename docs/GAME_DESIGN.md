# Project Oasis 游戏设计文档（v0.1.2 — Random Expedition）

本文档描述 v0.1.2 的全部实际实现规则与数值。所有可调数值集中在
`src/game/config/gameConfig.ts`，本文档与代码保持同步。

> v0.1.0/v0.1.1 的固定节点地图、三矿区、固定矿价、三日天气预报等规则已全部废弃，
> 历史 Balance Baseline（100/160/240）仅适用于旧版，见 docs/BALANCE_REPORT_v0.1.1.md。
> v0.1.2 的设计动机与 Breaking Changes 清单见 docs/RANDOM_EXPEDITION_v0.1.2.md。

## 1. 核心目标

玩家携带 2000 元从城市出发，在最大旅程天数内完成：
城市 → 穿越随机格子地图 → 抵达两个矿区之一 → 自行决定挖矿天数 → 沿不重复路线返回城市。
返回城市时携带的宝石按当局锁定的单价变现，最终资产 = 剩余现金 + 宝石销售额。

## 2. 时间系统

- 明确两个变量：`daysUsed`（已用天数，初始 0）与 `maxDays`（最大旅程天数，初始 42）。
  UI 显示「天数：X / Y」。
- 消耗 1 天的行为：移动 1 格、原地停留、绿洲休整、村庄打工（市集）、追回盗贼、挖矿 1 天。
- 额外损失 1 天：沙尘暴迷路、草地陷入泥沼。
- **购买天气预报包不消耗天数，而是永久 `maxDays - 1`**（见 §10）。
- `daysUsed > maxDays` 立即失败；`daysUsed == maxDays` 当天成功回城仍算成功。

## 3. 阶段（Phase）

| 阶段 | 含义 |
| --- | --- |
| OUTBOUND | 去程：城市出发前往矿区入口 |
| MINING | 采矿：在矿区入口挖矿 |
| RETURN | 返程：从同一矿区入口返回城市 |
| FINISHED | 结束（胜利或失败） |

## 4. 地图（v0.1.2 核心变更）

- **m×n 二维格子地图**，尺寸**固定为 10×12（120 格）**，属于游戏基础规则，
  不是按局随机的玩法参数。
- **城市固定左下角** `(rows-1, col) = (9, 0)`：起点、终点、允许重复、无随机遭遇。
- **两个矿区 Mine A / Mine B** 全部位于**最右列** `col = 11`，行由 Seed 随机：
  - 不重合；最小行距 ≥ 4（`gameConfig.map.mineMinRowGap`）；
  - 矿区不参与普通地形随机，无随机遭遇，天气恒晴。
- 除城市与矿区外的普通格地形**完全独立随机**（与位置、路线无关）：

| 地形 | 概率 |
| --- | --- |
| 草地 GRASS | 0.45 |
| 沙漠 DESERT | 0.30 |
| 村庄 VILLAGE | 0.15 |
| 绿洲 OASIS | 0.10 |

不存在预制安全通道、沙漠走廊或位置偏置：矿区附近不保证更危险，城市附近不保证更安全。

- 旧版 36 节点 / 59 条道路的固定路线体系已删除（node/edge/road 数据结构不再存在）。
- 同一 Seed 确定性生成完全相同的地图（地形、天气、遭遇、绿洲状态、矿区价值）。

## 5. 移动规则

- 只允许**上下左右四方向**移动，不允许斜向；每移动一格消耗 1 天。
- 禁止：越界、进入违反去返程重复规则的格子、中途返回城市、任何形式的瞬移。

## 6. 路线不可重复规则（核心规则保留）

- **去程**：普通格每格只能经过一次（被"烧掉"）；不允许中途回城；抵达任一矿区即进入 MINING。
- **返程**：不得经过去程已烧掉的普通格，返程自身也不得重复普通格。
- **豁免**：城市、当前进入的矿区。**另一个矿区不是豁免格**（返程不可进入）。
- 去程走过的普通格在返程中直接视为不可通行。

## 7. 无路可回判断（正式路径检测）

不依赖局部邻格判断，使用 BFS 全局路径检测（`hasLegalReturnPath`）：

- 进入矿区时：若无合法返城路径 → 立即失败（`RETURN_ROUTE_SEVERED`）；
- 开始返程时：同样检测；
- 返程每次关键行动后：路线被自己封死 → 立即失败；
- 去程被围死（无任何合法移动）→ 失败（`TRAPPED`）。

## 8. 地图合法性约束

生成时验证：城市与每个矿区之间存在**两条内部普通格完全不重合的路径**
（Menger 单点删除校验：删去任意一个非端点格后仍连通）。
不满足时以 `seed#mapRetryN` 确定性重试生成（上限 `gameConfig.map.maxRetries = 200`），
保证同一个主 Seed 最终仍得到相同地图。

矿区价值评估阶段（§9）若贪心搜索找不到合法往返组合，同样触发确定性重试。

## 9. 矿区动态价值（v0.1.2 核心变更）

旧版南 100 / 中 160 / 北 240 固定价格**已废弃**。两个矿区的宝石收购价每局由 Seed
在**地图生成时客观计算**，开局即可看到：

```
Mine A (row,col) ¥176/kg
Mine B (row,col) ¥238/kg
```

玩家从 Day 0 开始做风险收益选择。正常 UI 只展示价格，不公开内部评分公式。

### 9.1 评估因素（与玩家行为完全无关）

| 因素 | 权重（gameConfig.mineValuation） | 说明 |
| --- | --- | --- |
| 距离成本 | distanceWeight = 2.0 | 城市到矿区最短路跳数 |
| 去程地形风险 | outboundRiskWeight = 0.8 | 最低风险去程路径的地形风险和 |
| **返程困难度（核心）** | returnRiskWeight = 1.0 | 烧掉去程后最优返程的地形风险和 |
| 返程稀缺 | scarcityPerMissing = 5 | 备选返程走廊少于 3 条时逐条惩罚 |
| 天气复杂度 | weatherWeight = 0.25 | 去返程路径格 42 天内恶劣天气平均天数 |
| 随机扰动 | jitter 0.90~1.10 | 宝石质量 / 市场行情 / 矿脉差异 |

- 候选去程按「矿区每个邻格方向」枚举，对每个去程计算"烧掉它之后"的最优合法返程，
  取总代价最小的组合（与真实玩家最优规划一致）；另有「返程优先」兜底策略。
- `difficultyScore = 最短路×2.0 + 去程风险×0.8 + 返程风险×1.0 + 稀缺惩罚 + 天气负载×0.25`。
- `gemPrice = clamp(80, 320, round((30 + difficultyScore × 1.6) × jitter))`。
- 风险评级 estimatedRisk（★~★★★★★）基于 difficultyScore，阈值 [12, 40, 85, 115]。

### 9.2 防刷保证（正式规则）

价格**绝对不**依赖玩家实际行为：走过的沙漠数、绕路程度、耐力损失、装备使用、
遭遇的坏天气等一律不影响已生成的价格。价格在 `createNewGame` 时即客观存在，
进矿时只是读取锁定。开发模式可显示 `difficultyScore`，正常 UI 只显示价格。

## 10. 天气预报（v0.1.2 全部重做）

旧版「花 1 天查看未来 3 天」已废除。改为**单日局部预报 + 可储存次数**：

- 初始剩余预报次数 0。
- **购买天气预报包**：成本不是金钱，而是 **maxDays 永久 -1**（牺牲一天旅程预算）；
  获得 3 次预报，购买时立即自动使用 1 次 → 购买完成剩余 2 次，并立即显示预报。
  例：`0/42 → 0/41`，`12/41 → 12/40`；已有储存次数则累加（1 + 3 - 1 = 3）。
  若购买导致 `daysUsed > maxDays` 立即失败（UI 有禁用保护）。
- **储存**：次数不过期、不随天数减少、不因移动消失、可带入返程、
  可在任何正常行动阶段主动使用；使用不消耗天数/金钱/耐力（成本已在购买时支付）。
- **内容**：每次只预报**下一天**，不预报更远。
- **空间范围**：玩家当前格 + 周围一圈 8 邻域（内部 9 格 / 边缘 6 格 / 角落 4 格）。
- **与战争迷雾的关系**：未知格仍显示坐标与天气（这本身就是情报），
  但不把该格地形永久揭示为已探索。
- UI 显示「剩余天气预报次数」。

## 11. 原地停留（v0.1.2 新增）

- 普通可行动阶段可执行「原地停留 1 天」：`daysUsed += 1`，位置不变。
- 不赚钱、不回血、不获得宝石、不重新抽取遭遇、不自动触发绿洲恢复。
- **当天的天气仍正常结算**：所在格发生沙尘暴/高温等照常处理（等待也有代价）。
- 主要用途：等待恶劣天气过去。

## 12. 遭遇（按格预生成）

- 所有普通格的遭遇在**地图生成阶段按 Seed 预生成**，每格每局最多触发一次
  （通常在首次进入时）；原地停留/等待不重新抽取。
- 基础触发概率 `gameConfig.encounter.baseProbability = 0.25`（约每 4 个首次探索格出现 1 次）。
- 地形事件池：

| 地形 | 触发后事件 |
| --- | --- |
| 沙漠 | 商队（二选一：300 元二手帐篷 / 免费情报） |
| 村庄 | 盗贼 50% / 繁荣市集 50% |
| 草地 | 牧民指引（免费情报） |
| 绿洲 | 无额外遭遇（干涸是绿洲自身状态，Seed 预生成，概率 0.20） |
| 城市 / 矿区 | 无随机遭遇 |

- 天气与遭遇严格分离、可同日叠加，先天气后遭遇。
- 情报揭示范围：当前格**曼哈顿距离 ≤2** 的未知普通格（`gameConfig.intelRevealRadius`）。

## 13. 战争迷雾

- 初始可见：城市、两个矿区（含收购价）；普通格显示 `?`。
- 玩家第一次进入普通格 → 永久揭示地形；情报揭示的格子同样可见（不带永久探索含义的区分保留）。
- 天气预报不改变迷雾状态。

## 14. 耐力 / 装备 / 天气效果

与 v0.1.1 一致：初始耐力 5 上限 5；帐篷 400 元（3 次沙漠耐久）、指南针 100 元；
沙尘暴四象限规则不变；暴雨整顶报废帐篷；高温 -1 耐力；泥沼额外 +1 天。
城市与村庄可购买装备，繁荣市集当次访问八折（320/80）。

天气概率（按地形，v0.1.2 配置值）：

| 地形 | 晴 | 高温 | 沙尘暴 | 暴雨 | 泥沼 | 阴 |
| --- | --- | --- | --- | --- | --- | --- |
| 沙漠 | 0.32 | 0.30 | 0.38 | - | - | - |
| 草地 | 0.44 | - | - | 0.28 | 0.28 | - |
| 村庄/绿洲 | 0.70 | - | - | - | - | 0.30 |
| 城市/矿区 | 1.00 | - | - | - | - | - |

## 15. 采矿

- 进入矿区后每天挖 2 kg，玩家自行决定挖几天；矿区安全（无天气、无遭遇、无耐力伤害）。
- 返程必须从进入的同一矿区开始；进入矿区时锁定该矿区生成时评估的收购价。

## 16. 路线风险评分（仅供统计，不影响售价）

保留 v0.1.1 的路线风险评分与星级（★★~★★★★★），仅用于结算展示与仿真统计。
格风险系数：沙漠 4.5、草地 7.0、村庄 -3.5、绿洲 -2.5。

## 17. 金钱与结算

- 初始现金 2000；结算公式与 v0.1.1 一致（销售额 = 宝石 × 锁定价，净收益 = 最终资产 - 2000）。
- 结算显示：daysUsed / maxDays、去程/挖矿/返程天数、天气预报包购买数、宝石重量与成交价等。

## 18. 胜负条件

| 条件 | 结果 |
| --- | --- |
| `daysUsed <= maxDays` 时返回城市（带宝石） | 胜利 |
| 任何操作后 `daysUsed > maxDays` | 失败（超时） |
| 耐力归零 | 失败 |
| 返程不存在合法回城路径 / 进矿即被封 / 去程被围死 | 失败（路线中断） |

## 19. Modal 可退出性（P0 修复）

- 所有信息类 Modal：最大高度受视口约束（`max-height: 85vh`）、Header 固定、
  `×` 永远可见、支持 Esc、Footer 提供关闭按钮、内容过多时仅内部滚动。
- 事件类 Modal（必须决断）：不提供关闭，但选项永远可达，不允许任何无法退出的状态。
