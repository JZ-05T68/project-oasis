# Balance 调参日志

每轮调参记录 Before / Change / Reason / After。一次只改一个参数族。
数据来源：`npm run sim`（14 Bot × 10,000 Seeds/个，Seed 形如 `bal11:<Bot>:<i>`）。

---

## Tune #1 — 提高恶劣天气频率

- **日期**：2026-09-13
- **Before（reports/baseline，14 Bot × 10k）**：
  - 矿区对照：南矿 100% 胜 / EV 4276；中矿 99.8% / 7257；北矿 97.3% / 9387。
    北矿胜率仅比南矿低 2.7pp，EV 却高 2.2 倍 → 北矿明显支配。
  - 装备：CheapBot（0 购买）99.9% 胜 / EV 4943 优于 ShortestPathBot（1 帐篷+1 指南针）
    100% / 4473，远超 PreparedBot（3+2）100% / 3375；装备浪费率 28%~75%
    → 购买装备在 EV 上是纯亏损。
  - 采矿：GreedyMiner 96.1% / 4841（超时 3.9%）对比 ConservativeMiner 100% / 2834
    → 时间压力不足，贪心 +2000 EV 仅付出 3.9pp 胜率。
- **Change（gameConfig.weatherProbability）**：
  - 沙漠：晴 0.42→0.32，高温 0.28→0.30，沙尘暴 0.30→0.38
  - 草地：晴 0.62→0.44，暴雨 0.19→0.28，泥沼 0.19→0.28
  - （村庄/绿洲/城市/矿区不变）
- **Reason**：42 天预算与 2kg/天不可动，路线风险必须由天气真实消耗资源
  （耐力/帐篷/指南针/时间）才能形成风险-收益交换；同时修复装备无价值问题。
  草地仍然保持「低频但高代价」定位（约 1/3.6 格触发坏天气，但代价是整顶帐篷或耐力）。
- **After（reports/tune1，14 Bot × 10k，同 Seed 配对）**：
  - 矿区对照：南 100% / EV 4148；中 98.0% / 6991；北 88.5% / 8195（耐力死亡 2.7%→11.5%）。
  - 方向正确（北矿胜率 -8.8pp、耐力死亡 ×4.3、装备浪费 28→20%），但北矿 EV 仍为南矿 1.98 倍，
    「北矿收益最高且装备成本差异小」的禁止模式仍在。
  - 结论：天气杠杆方向正确但幅度不足，价格阶梯与风险阶梯不匹配需要价格工具。

## Tune #2 — 矿区固定价调整（价格扫描数据支持）

- **日期**：2026-09-13
- **Before（reports/tune1）**：南 100% / 4148；中 98.0% / 6991；北 88.5% / 8195（北/南 EV 比 1.98）。
- **Change（gameConfig.mineBasePrice）**：中央 180 → 160，北矿 280 → 240（南矿保持 100）。
- **Reason**：任务书允许「数据明确证明失衡后」修改矿区价格。两轮 10k 仿真 + 价格扫描
  （scripts/price-sweep.ts，6 组价格组合 × 4 Bot × 3000 Seeds）均证明北矿支配；
  扫描数据（北/南 EV 比）：280/180 → 1.99、260/170 → 1.81、240/160 → 1.70、220/150 → 1.53。
  选 240/160：保留「北矿单局收益最高 + 波动最大」的风险奖励阶梯，同时把 EV 压到不再支配的水平；
  避免继续加大天气强度（那会把全图变成生存绞肉机，破坏中低风险路线的体验）。
- **After（reports/tune2，14 Bot × 10k，同 Seed 配对）**：

  | 对照 | Before 胜率 / EV | After 胜率 / EV | 胜局中位资产（After） |
  | --- | --- | --- | --- |
  | SouthMineBot | 100% / 4148 | 100% / 4148（南价未动） | 6180 |
  | MiddleMineBot | 98.0% / 6991 | 98.0% / 6147 | 8220 |
  | NorthMineBot | 88.5% / 8195 | **88.5% / 6922** | **9840（最高，波动最大）** |

  - 北/南 EV 比：1.98 → **1.67**；北/中 EV 差：+1204 → +776（以 -9.5pp 胜率换取）。
  - 胜局收益阶梯正确：北 7899 > 中 6285 > 南 4148；资产波动阶梯正确：北 ±1440 > 中 ±1040 > 南 ±720。
  - 禁止模式（北矿 EV 最高 + 胜率最高 + 装备成本差异小）解除：北矿胜率三矿最低、波动最大。
