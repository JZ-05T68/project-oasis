## Tune #1 — 提高恶劣天气频率

- **日期**：2026-09-13
- **Before（reports/baseline，14 Bot × 10k）**：
  - 矿区对照：南矿 100% 胜 / EV 4276；中矿 99.8% / 7257；北矿 97.3% / 9387。
    北矿胜率仅比南矿低 2.7pp，EV 却高 2.2 倍 → 北矿明显支配。
  - 装备：CheapBot（0 购买）99.9% 胜 / EV 4943 优于 ShortestPathBot（1 帐篷+1 指南针）
    100% / 4473，远超 PreparedBot（3+2）100% / 3375；装备浪费率 28%~75%
    → 购买装备在 EV 上是纯亏损。
  - 采矿：GreedyMiner 96.1% / 4841（超时 3.9%）对比 ConservativeMiner 100% / 2834
    → 时间压力不足，贪心 +2000 EV 仅付出 3.9pp 胜率。
- **Change（gameConfig.weatherProbability）**：
  - 沙漠：晴 0.42→0.32，高温 0.28→0.30，沙尘暴 0.30→0.38
  - 草地：晴 0.62→0.44，暴雨 0.19→0.28，泥沼 0.19→0.28
  - （村庄/绿洲/城市/矿区不变）
- **Reason**：42 天预算与 2kg/天不可动，路线风险必须由天气真实消耗资源
  （耐力/帐篷/指南针/时间）才能形成风险-收益交换；同时修复装备无价值问题。
  草地仍然保持「低频但高代价」定位（约 1/3.6 格触发坏天气，但代价是整顶帐篷或耐力）。
- **After（reports/tune1，14 Bot × 10k，同 Seed 配对）**：
  - 矿区对照：南 100% / EV 4148；中 98.0% / 6991；北 88.5% / 8195（耐力死亡 2.7%→11.5%）。
  - 方向正确（北矿胜率 -8.8pp、耐力死亡 ×4.3、装备浪费 28→20%），但北矿 EV 仍为南矿 1.98 倍，
    「北矿收益最高且装备成本差异小」的禁止模式仍在。
  - 结论：天气杠杆方向正确但幅度不足，价格阶梯与风险阶梯不匹配需要价格工具。

## Tune #2 — 矿区固定价调整（价格扫描数据支持）

- **日期**：2026-09-13
- **Before（reports/tune1）**：南 100% / 4148；中 98.0% / 6991；北 88.5% / 8195（北/南 EV 比 1.98）。
- **Change（gameConfig.mineBasePrice）**：中央 180 → 160，北矿 280 → 240（南矿保持 100）。
- **Reason**：任务书允许「数据明确证明失衡后」修改矿区价格。两轮 10k 仿真 + 价格扫描
  （scripts/price-sweep.ts，6 组价格组合 × 4 Bot × 3000 Seeds）均证明北矿支配；
  扫描数据（北/南 EV 比）：280/180 → 1.99、260/170 → 1.81、240/160 → 1.70、220/150 → 1.53。
  选 240/160：保留「北矿单局收益最高 + 波动最大」的风险奖励阶梯，同时把 EV 压到不再支配的水平；
  避免继续加大天气强度（那会把全图变成生存绞肉机，破坏中低风险路线的体验）。
- **After（reports/tune2，14 Bot × 10k，同 Seed 配对）**：

  | 对照 | Before 胜率 / EV | After 胜率 / EV | 胜局中位资产（After） |
  | --- | --- | --- | --- |
  | SouthMineBot | 100% / 4148 | 100% / 4148（南价未动） | 6180 |
  | MiddleMineBot | 98.0% / 6991 | 98.0% / 6147 | 8220 |
  | NorthMineBot | 88.5% / 8195 | **88.5% / 6922** | **9840（最高，波动最大）** |

  - 北/南 EV 比：1.98 → **1.67**；北/中 EV 差：+1204 → +776（以 -9.5pp 胜率换取）。
  - 胜局收益阶梯正确：北 7899 > 中 6285 > 南 4148；资产波动阶梯正确：北 ±1440 > 中 ±1040 > 南 ±720。
  - 禁止模式（北矿 EV 最高 + 胜率最高 + 装备成本差异小）解除：北矿胜率三矿最低、波动最大。

## Tune #3 — v0.1.2b 地图缩小后的宝石经济重标定

- **日期**：2026-09-14
- **背景**：真人试玩 Round 1 反馈——「即使采取合理策略、安全完成远征并带回宝石，最终仍可能明显亏损」。
- **Before（v0.1.2a：10×12 地图 / base=10 / clamp 80~320，8 Bot × 3000 Seeds，
  `scripts/economy-calibrate.ts`）**：
  - 价格分布：min=80 p10=80 median=91 p90=137 avg=100.3，**触底占比 39.53%**、触顶 0%
    → 难度差异几乎不体现在价格上。
  - ReasonablePlayerBot：胜率 95.07%，但成功局盈利占比只有 **86.96%**、中位净收益 +760、
    **p10 净收益 −80**（即约 1/8 的成功局净亏损）。
  - CautiousPlayerBot（3 帐篷 + 2 指南针）：成功局盈利占比 **49.86%**、中位净收益 0、p10 −720
    → 「合理但偏保守」的玩法基本是白干。
- **根因**：8×9 把客观难度分整体压缩（往返 20~30 天、普通格 18~28 个；
  难度分 p10/中位/p90 = 16/40.5/63.5，旧地图约 120~230）。
  沿用 `base=10`，`base + 难度 × 2.0` 只有 30~110 元/kg，被下限 80 大面积夹住。
- **Change（gameConfig.mineValuation）**：`base 10 → 140`、`clampMin 80 → 140`；
  **斜率 scale=2.0 与上限 clampMax=320 保持不变**（保留矿区之间的相对差异，不因小地图抬高上限）。
  计价规则本身不动：单价基数仍**只**由「最短合法往返方案的客观危险程度」决定，
  与玩家实际路线/受伤/装备消耗完全无关。
- **After（同规模 8 Bot × 3000 Seeds）**：
  - 价格分布：min=140 p10=172 median=221 p90=267 max=320 avg=220.09，
    触底 **1.75%**、触顶 0.21%。
  - ReasonablePlayerBot：胜率 95.07%、平均宝石 25.12kg、平均收入 5545、平均装备支出 1563、
    平均净收益 **+3913**、中位 **+3880**、p10 **+2018**、成功局盈利占比 **99.96%**。
  - CautiousPlayerBot：胜率 96.47%、成功局盈利占比 98.34%、中位净收益 +2440、p10 +796。
  - 装备支出仍然有意义：WastefulBot（5 顶帐篷 + 3 指南针）净收益比 ReasonablePlayerBot 低；
    「只挖 1 天 + 常规装备 900 元」= **−458 元**（亏损 ✓）。
- **没有保底**：未引入 `max(cost+profit, revenue)` 之类夹取；失败局宝石销售额恒为 0 → 必然亏损。
  冒险玩法仍会死：GreedyMinerBot 胜率 48.3%（EV 2584 vs 胜局均收益 6427）、
  CheapBot（0 装备）胜率 22.87%。详见 tests/economy.test.ts 的三条性质回归。
- **报告**：reports/economy-calibration.md（含旧配置 / 下界 / 选定 / 上界四组参数对照）。
- **备注 / 已知问题**：本轮只重标定了价格映射，没有改「价格基数 = 最安全最短往返方案风险」
  这条定价规则本身。由于负风险地形（村庄 -3.5 / 绿洲 -2.5）会被次准则优先选中，
  更长的往返有时反而被评为「更不危险」，导致远端矿区不再必然更值钱——
  这一现象**已记录未修改**，留给第二轮真人试玩后决定是否调整规则。

## Tune #4 — 草地暴雨不使用帐篷：耐力 -1 → -2（本轮试玩值）

- **日期**：2026-09-14
- **来源**：Human Playtest Fix Round 1 —— 真人试玩确认「硬扛暴雨代价太轻」，
  玩家倾向于不带帐篷赌天气，远征张力不足。这是**本轮试玩参数**，不代表最终永久值。
- **Before（v0.1.2b 首轮配置 / 8 Bot × 1200 Seeds[^1]，`scripts/economy-calibrate.ts`）**：
  - 草地暴雨「不使用帐篷」耐力 -1（`rainstormStaminaCost = 1`）。
  - 3000 局标定下 ReasonablePlayerBot 胜率 95.07%、成功局盈利占比 99.96%。
- **Change（gameConfig）**：
  - 新增结构化 `gameConfig.weather.grassRain.staminaLossWithoutTent = 2`，并删除
    `heatStaminaCost` / `sandstormStaminaCost` / `rainstormStaminaCost` 三个扁平字段
    （统一收进 `gameConfig.weather.*`，避免同一数值散落两处）。
  - 引擎两条路径同时改：① 没有帐篷时到达暴雨格直接结算；② 有帐篷但玩家选择硬扛。
  - 「使用帐篷」分支不变：整顶报废、耐力不减，由玩家自选具体哪一顶。
  - **其它数值一律未动**：初始资金 2000、初始耐力 5/5、帐篷 400/耐久 3、指南针 100、
    maxDays 42、采矿 2kg/天、遭遇 35%、草地 40/沙漠 30/村庄 20/绿洲 10、
    天气概率表、绿洲干涸 20%、预报包 3 次（自动用 1 次）全部保持原值。
- **After（8 Bot × 1200 Seeds = 9600 局，同规模对照）**：
  - 价格分布（选定配置 base140 / scale2.0 / clamp 140~320）：min=140 p10=172 median=220
    p90=266 max=320 avg=219.63，触底 **1.86%**、触顶 0.18%（上一轮为 1.75% / 0.21%，
    差异来自采样规模，不是规则改动）。
  - ReasonablePlayerBot：胜率 **90.75%**（上一轮 95.07%）、平均宝石 25.14kg、
    平均收入 5552.41、平均装备支出 **1540.03**、平均净收益 **+3921.72**、
    中位 +3940、p10 **+1942**、**成功局盈利占比 100%**。
  - 结论：-2 明显提高了生存压力（合理玩法胜率 -4.3pp），但**没有破坏正收益预期**——
    合理成功局仍然全部盈利，p10 净收益仍为正。这就是本轮想要的"更紧张但不惩罚理性决策"。
  - 亏损空间仍在（§6）：只挖 1 天（2kg）+ 常规装备 900 元 → **-460 元**；
    CheapBot（不买装备）胜率仅 10.08%、EV 444；GreedyMinerBot 胜率 42%（EV 2103 vs 胜局均收益 7619）。
  - 刷价漏洞检查（§19/§20）：**否**。单价仍只由 `difficultyScore`（地图生成阶段按
    「最短合法往返方案」客观风险一次算出）与 jitter 决定，玩家绕路 / 受伤 / 烧帐篷 /
    原地等待都不改变它；同长度多解取风险最低者。
- **报告**：`reports/economy-calibration.md`（含旧配置 / 下界 / 选定 / 上界四组参数对照）。
- **已知问题（工具链，非玩法）**：本次先用 `--runs 3000 --workers 8` 跑到 12000 局后，
  worker 子进程在高并发下不再退出，标定整体挂住（已确认不是某个 Seed 的死循环：
  单进程跑 ReasonablePlayerBot 正常）。已给 `scripts/economy-calibrate.ts` 加
  **每分片 120s 看门狗**（超时杀子进程并跳过该片、明确报告跳过清单），
  改为 `--workers 4` 后 9600 局 202s 正常跑完。

[^1]: 本轮按「允许数千局专项经济模拟、不要启动几十万局大规模 Balance Validation」的约束
    使用 8 Bot × 1200 Seeds（9600 局）；上一轮的 3000×8 数字作为方向性对照。

## 2026-09-15 · Autonomous Mechanism Evolution Lab（5 小时自动机制演化实验）

**目标**：让「到矿后继续挖 vs 现在返程」产生真实抉择（Goal A）；让返程不只是「沿还能走的格子回来」（Goal B）；
并重新标定帐篷价格。

**方法**：13 个机制候选 + 13 个参数点 + 8 档帐篷价格，全部走
`Shadow Experiment → 大样本验证 → Promotion Gate → 正式落盘 → 全量回归`。
所有候选与所有 Bot 共用同一批 Seed（逐局配对），决策改变率的一级指标定义见
`reports/mechanism-autolab/MECHANISM_5H_AUTOLAB_REPORT.md`。

**结论**：
- **落盘机制（1 个）**：负重返程（§15.1）。载重 ≥24kg 后每多 6kg，返程过沙漠每格 +1 天；可主动丢弃宝石。
  实测采矿决策改变率 **82%**、无支配策略（最热采矿模板占 45%）、合理玩家胜率仍在健康带。
- **落盘数值（1 项）**：`tentPrice` 700 → **625**。8 档扫描下 625 是**唯一**同时满足
  「3 顶买得起 / 4 顶买不起」硬约束与两条 antiWasteful 判据（WastefulBot 的 EV 与胜率都低于合理玩家）的档位。
- **被否决**：纯递减产量（M01/M02）、矿区生产力差异（M07）——决策改变率恒为 **0%**，
  因为任何 >0 的日产量都仍然值得挖，提前返程没有收益；事故风险（M03/M04）有效但把 EV 压到 51~71%。
  详见实验报告 §Top Rejects。
- **仍不可达**：返程**路线**选择（见 §15.2 与 GAME_DESIGN §15.2）。

**方法学记录（避免下次重复踩坑）**：见 `reports/mechanism-autolab/harness-check.md` 与实验日志的「失败与回滚记录」。
